# 日常日本語｜單字練習

以《ワニさん日文一上》講義第 8–36 頁為基礎整理的日文單字學習網站，提供課次瀏覽、假名與漢字、日文例句、插圖、語音播放和諧音聯想。

## 目前內容

- 共 91 張單字卡，附繁體中文釋義與例句翻譯
- 第四課 p.67–82 收錄 59 張專屬詞卡，包含生活、食物、動物與觀光用語
- 依講義第一課到第五課分類；日期時間保留第三、四課共用分類
- 每張卡顯示假名、漢字表記、OpenMoji 插圖和記憶提示
- 使用瀏覽器日文語音播放，支援手機及桌機版面

## GitHub Pages

專案使用 GitHub Actions 將根目錄的 index.html 部署到 Pages。首次設定請到 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**。推送至 main 後會自動部署。

## 專案規則

開始修改前請先讀 AGENTS.md，其中定義新增詞彙、漢字、例句、插畫和課次分類的方式。
